========================================
奶酪大盜 Cheese Thief - 使用說明
========================================

一款適合 5～8 人遊玩的瀏覽器連線桌遊。


----------------------------------------
線上遊玩
----------------------------------------
直接開啟以下網址即可遊玩：

    https://gx1108.github.io/Cheese-thief/

這是已部署完成的 GitHub Pages 線上版本，不需要安裝軟體或下載檔案，
手機、平板或電腦都可以使用。每位玩家使用自己的裝置連線到同一個遊戲房間。


----------------------------------------
遊戲方式
----------------------------------------
1. 每位玩家開啟線上網址，輸入自己的暱稱。
2. 一位玩家按「創建遊戲」，選擇公開或非公開房間及遊戲模式。
3. 其他玩家按「加入遊戲」，從房間列表選擇房間，或輸入房號加入。
4. 房間達到最低人數後，由房主開始遊戲。一般模式至少需要 5 人，最多 8 人。
5. 每位玩家在自己的裝置查看身分與骰子點數，查看後請保密。
6. 依照畫面提示進行黑夜行動、白天討論與投票。
7. 遊戲結束後，畫面會公布所有玩家的角色、骰子點數、票數與勝利陣營。

遊戲內有角色介紹與規則介紹按鈕，第一次遊玩時可以先閱讀。建議使用最新版 Chrome、Edge、Safari 或 Firefox，
並允許瀏覽器播放音效；若不想播放聲音，可以在遊戲內調整音量。


----------------------------------------
離線遊玩
----------------------------------------
沒有網路時，也可以下載專案後直接開啟根目錄的 game.html：

    game.html

這個版本是單一裝置輪流遊玩，不需要 Node.js 或其他安裝程式；若要多人各自使用手機，請使用上方的線上網址。


----------------------------------------
開發者資訊：連線多人版
----------------------------------------
專案也保留 Node.js 連線多人版的原始碼，位於 server/ 資料夾。線上網站的前端會透過 WebSocket
連線到已部署的遊戲伺服器；開發者也可以在本機啟動自己的伺服器測試。

在本機啟動：

    cd server
    npm install
    npm start

伺服器啟動後，使用瀏覽器開啟：

    http://localhost:8080

如需修改遊戲內容，主要檔案如下：

    game.html              單一裝置版前端
    server/server.js       連線多人版後端
    server/public/index.html 連線多人版前端


----------------------------------------
常見問題
----------------------------------------
Q: 線上網址打開後畫面空白？
A: 請重新整理頁面，或改用最新版 Chrome、Edge、Safari 或 Firefox；也可以確認瀏覽器沒有封鎖圖片或音效。

Q: 可以讓每個人用自己的手機一起玩嗎？
A: 可以，所有玩家開啟同一個線上網址後，輸入暱稱並加入同一個房間即可。房主需要等房間達到最低人數後開始遊戲。

Q: 本機執行 npm start 時出現「無法辨識」？
A: 請先安裝 Node.js LTS，安裝完成後重新開啟 PowerShell，再執行 npm install 與 npm start。
